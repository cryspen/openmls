* Overview

This directory holds the Lean 4 / [[https://github.com/AeneasVerif/aeneas][Aeneas]] proof development for the *ratchet-tree math* of
OpenMLS (RFC 9420 §4 / Appendix C, ported to Rust in
=openmls/src/binary_tree/array_representation/treemath.rs=).

The Rust functions carry =hax_lib= annotations (=requires= / =ensures=); Charon extracts them to
LLBC and Aeneas to Lean. We discharge, in Lean, the proof obligations Aeneas generates: each
function is panic-free on its stated precondition and meets its stated postcondition.

** The proof scheme

- *One theorem per obligation.* =Openmls/Extraction/ProofObligationsExplicit.lean= is the
  hand-derived reference view of all *19* obligations in explicit Hoare-triple form
  (=(pre).holds → ⦃⌜True⌝⦄ f args ⦃⇓ res => (post).holds / True⦄=). =Proofs.lean='s theorem
  statements must correspond 1:1 to it (same names, same triples). The reference file is not
  imported; its proofs stay =sorry=.
- *Stepping* is done by =hax_mvcgen= (fallback: plain =mvcgen= + local massaging at spans where
  it misbehaves). After stepping, residual goals must be pure scalar/bit arithmetic.
- *Loop invariants* are stated separately, one =*_loop_spec= theorem per loop via the generic
  =loop_spec_measure= driver in =Common.lean=.
- *Pure-spec exception (validated):* some official posts are too costly/weak to consume at
  call sites; validated companion specs fill the gap — =level.spec_pure= (registered; =level=
  itself no longer carries an obligation), =parent.spec_value= and =direct_path.spec_pure=
  (both unregistered, consumed via mvcgen's erasure =- <official>.spec.proof= at call sites).
  New pure specs require explicit user validation, case by case.
- *Sorry style:* a remaining =sorry= sits under its own explicit bullet / =case= block with a
  =-- TODO(arith): …= comment; a bare =all_goals sorry= is allowed only when *every* remaining
  goal is sorried. No =sorry= may hide inside a =first | … | sorry= chain, and no goal
  containing a Hoare triple / =wp⟦…⟧= may be sorried (that indicates broken stepping).
